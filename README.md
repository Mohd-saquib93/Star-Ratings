# ⭐ Star Rating Component

A simple and interactive **Star Rating component** built using **React**.  
This component allows users to select a rating by clicking on stars and is commonly used for feedback, reviews, and user experience scoring.

The project focuses on React state management and interactive UI behavior.

---

## 🚀 Features

- ⭐ Clickable star rating system
- 🔢 Supports multiple rating values (e.g. 1–5 stars)
- ⚡ Instant UI update on selection
- 🎨 Clean and minimal design
- 🧩 Reusable React component

---

## 🛠️ Tech Stack

- **React**
- **JavaScript (ES6+)**
- **CSS / Tailwind CSS** (for styling)
